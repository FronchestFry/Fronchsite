Server Datapack

This was a project of several years ago, in my early days of programming. It was one of my first major undertakings in a large scale project, and I spent quite a bit of time on it. The task was to make a pack for a Minecraft server, with a custom-built item for each player, a system to manage the item's production and removal from, and a way to unlock the item. Feel free to right click and open the img in a new tab to try to read the code. A minor note is that is was made for an old version, so the up-to-date editor where I took the screenshot registers some things as errors when they actually aren't. Please ignore the alleged errors, the code works.

Pychat

Please pardon the rooster popup (from the shenanigans page). He's there to obstruct my ip address from the server connect message. Despite me demonstrating with both instances on one computer, this was in fact a functional LAN wifi chatroom. Some friends and I were in a Python class in high school, sat on opposite sides of the room and got bored during the final weeks. As a result, we decided to create a chat room to talk and generally mess around. It is in two parts, a client, and a server. Every chatter runs the client, and whoever is hosting runs the server as well. The IP of the host does need to be manually edited in the code of the server, but once it's there you just boot it up, choose a name, and connect. We even added notification sounds, custom UIs, and shortcuts for emotes and common phrases, and direct name mentions. Some prankster even made an invisible message they could send that would blare the metal pipe sound in everyone's ears. As we each made our own custom client based off the basic core, many ideas were tested and developed. Was it internet-level-secure? Almost certainly not, but thankfully it was just a wifi procedure, and didn't actually have any internet access. If it did, the school wifi security would likely have blocked it.

TexDeck was a text-based deckbuilding game, inspired by slay the spire and Inscryption, produced in python, with some cards and jokes are taken from various media I watch, such as the gravity falls episode "Dungeons, Dungeons, and more Dungeons". I made it for prep week 2 of hackclub, and it was a fun challange building the engine, though later production lost some momentum as it transitioned from engine-code to game design, which is much further from my typical range of talents.
